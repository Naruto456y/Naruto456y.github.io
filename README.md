# 🧸 Магазин игрушек "ЖК Дубровка"

Полноценный интернет-магазин с клиентской частью и административной панелью. Проект создан для практики и представляет собой готовое решение для небольшого бизнеса.

## 📌 О проекте

Сайт состоит из двух основных частей:

- **Клиентская часть** (`index.html`) — то, что видят покупатели: каталог товаров, корзина, оформление заказов, чат с администратором, отзывы.
- **Административная панель** (`admin.html`) — управление заказами, товарами, категориями, модерация чата и отзывов.

## 🛠️ Технологии

- HTML5, CSS3
- JavaScript (ES6)
- JSON (хранение данных о товарах)
- MockAPI (хранение заказов и отзывов)

## 🚀 Функционал

### Для покупателей
- Просмотр каталога с фильтрацией по категориям
- Поиск товаров
- Добавление в корзину и оформление заказа
- Онлайн-чат с администратором
- Система отзывов (добавление, редактирование, удаление)

### Для администратора
- Управление заказами (изменение статуса, просмотр деталей)
- Модерация сообщений в чате
- Управление отзывами
- Добавление/редактирование/удаление товаров и категорий
- Экспорт данных в JSON
