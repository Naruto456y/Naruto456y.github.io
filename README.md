# Сайт-витрина для магазина игрушек 🧸

Это код моего первого сайта, который я делаю для практики. На нём можно будет посмотреть ассортимент игрушек.

### 🔍 Что тут есть

*   **`index.html`** — главная страница сайта.
*   **Папка `demo_img_plush/`** — здесь лежат картинки игрушек для отображения на сайте.
*   **`info_about_toys_plush.json`** — файл с описанием и ценами на плюшевые игрушки.
*   **`info_about_toys_simple.json`** — файл с описанием и ценами на обычные игрушки.

### 🚀 Как это работает

Сайт загружает данные из JSON-файлов и показывает игрушки с картинками. Это простой способ хранить информацию о товарах отдельно от кода страницы.
